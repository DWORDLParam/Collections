CV2SQL 2025

Данная утилита предназначена для конвертации xml файла содержащего метаданные CV (calculation view) БД HANA в формат SQL. 
Утилита создана с целью ускорения и упрощения анализа данных формируемых в CV, т.к. имеющийся инструментарий (например eclipse modeler) представляет данные в виде графической модели скрывая от пользователя динамически расчитываемые поля, условия выборок, праметры агрегации и другие характеристики CV. Чтобы воспользоваться утилитой вам необходимо выгрузить нужную вам сивишку в формат xml (в эклипсе это кнопка "Display XML"), затем сохранить xml в локальную папку, запустить данный python скрипт передав в качестве параметров папку с xml файлами и папку куда необходимо будет сохранить результат (без параметров утилита будет работать с папкой в которой она расположена)

например:
python D:\Python\Projects\scripts\CV2SQL\main.py D:\xml_dir D:\sql_dir 

Внимание! Утилита не выполняет сто процентную конвертацию! Результирующий SQL скрипт в некоторых случаях не сможет выполняться т.к. будет содержать синтаксические ошибки. Это обусловлено неопределенностями в структурах некоторых CV, отсутствием описания элементов структуры, а также многообразием лексем языка Calculation Engine для которого необходимо создавать соответствующие конвертеры. 


Доработка утилиты приветствуется.
